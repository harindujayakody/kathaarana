Visitors and readers

Stats come from Cloudflare and the site's database, so they're in the online dashboard: kathaarana.com/admin/.
Visitor numbers need a Cloudflare token. Story numbers below already work.
  1. Cloudflare → My Profile → API Tokens → Create Token → Custom token.
  2. Permission: Account · Account Analytics · Read (your account).
  3. In the worker folder run npx wrangler secret put CF_ANALYTICS_TOKEN and paste it at the prompt.
